## 2. 分析与结论

### 2.1 最佳模型

**Concat 融合模型**表现最佳：
- R² = 0.6508（解释了65%的方差）
- RMSE = 0.0846
- MAE = 0.0329
- mIoU = 0.8016

### 2.2 融合策略对比

| 融合方式 | R² | 说明 |
|----------|-----|------|
| **拼接 (Concat)** | 0.6508 | 最佳，两个分支信息完整保留 |
| 加法 (Add) | 0.6158 | 次优，特征直接相加 |
| Cross-Attention | -0.2599 | 最差，可能存在训练问题 |

### 2.3 分支消融分析

| 分支 | R² | 说明 |
|------|-----|------|
| 2D-Only | 0.5173 | 图像信息贡献较大 |
| 1D-Only | 0.0130 | 时序信息贡献较小 |
| Full (Cross-Attn) | -0.2599 | **负值，说明多模态融合失败** |

**问题诊断**：Cross-Attention 融合方式下，模型无法有效整合双模态信息，反而性能下降。建议使用 Concat 或 Add 融合。

### 2.4 ViT 模型性能问题

ViT-Small 模型 R² = -5.6298，表现极差。可能原因：
1. 训练不充分
2. 学习率不匹配（ViT 通常需要更小的学习率）
3. 数据量不足以训练 Transformer

### 2.5 时间偏移预测

Offset-2（预测0.1秒后）R² = 0.0826，性能较低但为正值，说明模型具备一定的时间预测能力。

## 3. 建议

### 3.1 推荐配置

```bash
# 最佳融合配置
python run_train.py --mode train --backbone_2d resnet18 --backbone_1d cnn_attn --fusion concat --epochs 100

# 或加法融合（次优但简单）
python run_train.py --mode train --backbone_2d resnet18 --backbone_1d cnn_attn --fusion add --epochs 100
```

### 3.2 避免使用

- Cross-Attention 融合（当前性能为负）
- ViT-Small（未充分训练时不推荐）
- 时间偏移预测（当前性能较低）

### 3.3 进一步优化方向

1. **检查 Cross-Attention 实现**：为什么性能为负？
2. **增加训练轮数**：特别是 ViT 模型
3. **调整学习率**：ViT 可能需要 1e-4 或更小
4. **增加数据量**：Transformer 通常需要更多数据
