# 调参与算法工程指导文档

> PE-MMNet v4 损失函数配置与调参指南

---

## 一、损失函数架构

总损失函数：

```
L_total = λ_mse · L_mse + λ_mono · L_mono + λ_loc · L_loc + λ_conf · L_conf
```

| 损失分量 | 默认权重 | 物理含义 |
|----------|----------|----------|
| **L_mse** | 1.0 | 裂纹密度 MSE 损失 |
| **L_mono** | 0.1 | 单调性约束（物理自洽） |
| **L_loc** | 1.0 | 定位损失（DIoU） |
| **L_conf** | 1.0 | 置信度损失（BCE） |

---

## 二、各损失详解

### 2.1 L_mse - 密度预测损失

**作用**：直接优化裂纹密度预测精度

**原理**：
```python
L_mse = MSE(pred_density, target_density)
```

**调参建议**：
- 密度预测不准（R² 低）→ 增大 λ_mse
- 其他指标正常但密度偏差大 → 单独调这个

### 2.2 L_mono - 单调性约束损失

**作用**：保证物理自洽性（裂纹不可逆）

**原理**：
```python
L_mono = Σ max(0, pred[i+1] - pred[i]) / (n-1)
```

仅当密度下降（违反单调性）时计算惩罚。

**为什么默认只有 0.1？**

1. 物理约束是"软约束"，不是主要目标
2. 过大会牺牲密度预测精度
3. 保持平衡：R² vs 物理自洽性

**调参建议**：
- 违反率高（>60%）→ 增大 λ_mono（如 0.2~0.5）
- 注意：增大可能导致 R² 下降

### 2.3 L_loc - 定位损失

**作用**：优化边界框定位精度

**原理**：DIoU Loss
```python
L_loc = DIoU(pred_box, target_box)
```

DIoU = IoU - (center_dist² / diag²)

**调参建议**：
- mIoU 低 → 增大 λ_loc（如 2.0）
- 位置预测不准 → 单独调这个

### 2.4 L_conf - 置信度损失

**作用**：判断裂纹是否存在

**原理**：BCE Loss
```python
L_conf = BCE(pred_conf, target_conf)
```

其中 target_conf = 1 if density > 0.5 else 0

## 三、命令行调参

### 3.1 调参格式

```bash
python run_train.py --mode train \
    --epochs 150 \
    --lambda_mono 0.2 \
    --lr 1e-4
```

### 3.2 场景化调参

**场景 A：mIoU 低（位置差）**
```bash
python run_train.py --mode train --epochs 150 --lambda_loc 2.0
```

**场景 B：密度预测不准（R² 低）**
```bash
python run_train.py --mode train --epochs 150 --lambda_mse 2.0
```

**场景 C：物理违反率高**
```bash
python run_train.py --mode train --epochs 150 --lambda_mono 0.5
```

**场景 D：综合调参（推荐）**
```bash
# 1. 先用默认配置观察 baseline
python run_train.py --mode train --epochs 150

# 2. 根据评估结果调整
# 如果 R²>0.9 但违反率>60% → 调高 lambda_mono
# 如果 R²<0.8 → 调高 lambda_mse

# 3. 微调示例
python run_train.py --mode train --lambda_mse 1.5 --lambda_mono 0.2
```

## 四、学习率调参

### 4.1 默认学习率

| 架构组合 | 默认学习率 |
|----------|------------|
| ResNet18 + CNN-Attn | 3e-4 |
| ViT + Transformer | 1e-4 |

### 4.2 调整学习率

```bash
# 降低学习率（更稳定但可能更慢）
python run_train.py --mode train --lr 1e-4

# 提高学习率（更快但可能不稳定）
python run_train.py --mode train --lr 5e-4
```

---

## 五、其他关键参数

### 5.1 Dropout

```bash
# 默认 0.2，防止过拟合
python run_train.py --mode train --dropout 0.3
```

### 5.2 早停耐心值

```bash
# 默认 20 epoch 无改善则停止
python run_train.py --mode train --patience 30
```

### 5.3 图像分辨率

```bash
# 更高分辨率 = 更好精度 + 更慢速度 + 更多显存
python run_train.py --mode train --image_size 768
```

## 六、调参检查清单

每次调参后，评估以下指标：

| 指标 | 期望方向 | 说明 |
|------|----------|------|
| R² | ↑ | 决定系数，越高越好 |
| RMSE | ↓ | 均方根误差，越低越好 |
| mIoU | ↑ | 定位精度，越高越好 |
| 违反率 | ↓ | 物理自洽性，越低越好 |

---

## 七、常见问题

**Q: 训练 loss 是 NaN？**
A: 降低学习率 `--lr 1e-4` 或 `--lr 5e-5`

**Q: 违反率很高（>70%）？**
A: 增大 `--lambda_mono 0.3`

**Q: 密度预测偏低？**
A: 检查数据标签，或增大 `--lambda_mse 1.5`

**Q: 显存不足？**
A: 使用 `--image_size 256 --batch_size 4`
