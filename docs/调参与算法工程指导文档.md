# 调参与算法工程指导文档

> PE-MMNet v4 损失函数配置与调参指南

---

## 一、损失函数架构

### 1.1 基础模型 (resnet18)

```
L_total = λ_mse · L_mse + λ_mono · L_mono + λ_loc · L_loc + λ_conf · L_conf
```

| 损失分量 | 默认权重 | 说明 |
|----------|----------|------|
| L_mse | 1.0 | 密度MSE损失 |
| L_mono | 0.1 | 单调性约束 |
| L_loc | 1.0 | 定位损失(DIoU) |
| L_conf | 1.0 | 置信度损失(BCE) |

### 1.2 YOLO变体

```
L_total = λ_box · L_box + λ_conf · L_conf + λ_mono · L_mono
```

### 1.3 DETR变体

```
L_total = λ_bbox · L_bbox + λ_conf · L_conf + λ_mono · L_mono
```

---

## 二、各损失详解

### L_mse - 密度预测损失

直接优化裂纹密度预测精度。

```bash
# 密度预测不准 → 增大
python run_train.py --lambda_mse 2.0
```

### L_mono - 单调性约束

保证物理自洽性（裂纹不可逆）。

```bash
# 违反率高 → 增大
python run_train.py --lambda_mono 0.3
```

### L_loc - 定位损失

DIoU Loss，优化边界框定位精度。

```bash
# mIoU低 → 增大
python run_train.py --lambda_loc 2.0
```

## 三、调参场景

| 场景 | 指标问题 | 调参建议 |
|------|----------|----------|
| 密度预测不准 | R² 低 | `--lambda_mse 2.0` |
| 物理违反率高 | >60% | `--lambda_mono 0.3` |
| 位置预测不准 | mIoU 低 | `--lambda_loc 2.0` |

**调参流程**：
1. 先用默认配置观察 baseline
2. 根据评估结果针对性调整
3. 微调示例：`--lambda_mse 1.5 --lambda_mono 0.2`

## 四、学习率调参

| 架构 | 默认学习率 |
|------|------------|
| ResNet18 + CNN-Attn | 3e-4 |
| ViT / Swin | 1e-4 |
| YOLO/DETR变体 | 1e-4 |

```bash
# 降低学习率（更稳定）
python run_train.py --lr 1e-4

# 提高学习率（更快但可能不稳定）
python run_train.py --lr 5e-4
```

## 五、高级优化参数

### 5.1 ThermalCutMix

物理安全增强（仅混合温度通道）。

```bash
python run_train.py --aug_cutmix_prob 0.3
```

### 5.2 密度一致性损失

邻域网格密度平滑约束。

```python
from training.mono_loss import CombinedDensityLoss

criterion = CombinedDensityLoss(
    lambda_mse=1.0,
    lambda_consistency=0.5,
    grid_size=16
)
```

## 七、常见问题

| 问题 | 解决方案 |
|------|----------|
| Loss 是 NaN | `--lr 1e-4` |
| 违反率高 | `--lambda_mono 0.3` |
| 密度预测偏低 | 检查标签或 `--lambda_mse 1.5` |
| 显存不足 | `--image_size 256 --batch_size 4` |
