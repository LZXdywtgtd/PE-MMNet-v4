# 项目算法与训练实验设计报告

> PE-MMNet v4 多模态裂纹预测系统

---

## 一、问题背景

日用陶瓷在热震过程中会产生裂纹，需要实时预测裂纹的位置、尺寸和密度。

**物理约束**：
- 裂纹密度随温度下降（热应力增加）单调递增
- 裂纹一旦产生不会消失（不可逆性）
- 裂纹位置与应力集中区域相关

---

## 二、算法设计

### 2.1 非对称双分支架构

```
输入
├── 1D 分支：温度时序 (batch, 300)
│   └── Micro + Macro 1D-CNN + Self-Attention → 64 维特征
└── 2D 分支：温度场+应力场 (batch, 2, 256, 256)
    └── ResNet-18 → 512 维特征

融合：Cross-Attention → 576 维融合特征
输出：根据任务类型
├── detection: (batch, 6) → [x, y, l, w, conf, density]
├── segmentation: (batch, 1, 256, 256) → 二值掩膜
└── multitask: (mask, detection) 元组
```

### 2.2 1D 分支设计

**输入**：300 点温度时序（10Hz × 30s）

**网络结构**：
1. Micro 1D-CNN（kernel=3, dilation=1）：捕捉瞬态温度跳变
2. Macro 1D-CNN（kernel=7, dilation=3）：提取长程热耗散趋势
3. 双分支并行 → Concat → LayerNorm → MultiHead Self-Attention → GlobalAvgPool
4. **输出**：64 维特征向量

### 2.3 2D 分支设计

**输入**：256×256 双通道图像（温度场 + 应力场）

**网络结构**：ResNet-18 预训练骨干（适配 2 通道输入）

**输出**：512 维特征向量

### 2.4 Cross-Attention 融合

双向交叉注意力实现"时域驱动力 × 空间薄弱位置"的物理耦合：

```
方向1（图像查询温度）：attn_2d→1d = softmax(Q_2d · K_1d^T / √d_k) · V_1d
  → 温度场中哪个位置对应高温/低温梯度？

方向2（温度查询图像）：attn_1d→2d = softmax(Q_1d · K_2d^T / √d_k) · V_2d
  → 温度变化应该关注图像中的哪个空间区域？

融合：concat([fused_2d, fused_1d]) → 576 维 (512+64)
```

## 三、损失函数设计

### 3.1 总损失函数

```
L_total = λ_mse · L_mse + λ_mono · L_mono + λ_loc · L_loc + λ_conf · L_conf
```

| 损失分量 | 物理原理 | 默认权重 |
|----------|----------|----------|
| **L_mse** | 直接惩罚密度预测误差 | 1.0 |
| **L_mono** | 格里菲斯断裂准则：裂纹不可逆递增 | 0.1 |
| **L_loc** | DIoU Loss：定位裂纹边界框 | 1.0 |
| **L_conf** | BCE Loss：判断裂纹是否存在 | 1.0 |

### 3.2 单调性损失详解

```python
L_mono = Σ max(0, pred[i+1] - pred[i]) / (n-1)
```

仅当密度下降（违反单调性）时计算惩罚。

## 四、模型变体（消融实验）

| 变体 | 说明 | 用途 |
|------|------|------|
| `full` | 完整 MM-DBFNet | 基线 |
| `1d_only` | 仅时序分支 | 验证 1D 信息贡献 |
| `2d_only` | 仅空间分支 | 验证 2D 信息贡献 |
| `concat` | 双分支拼接融合 | 验证融合策略 |
| `add` | 双分支加法融合 | 验证融合策略 |
| `cross_attn` | Cross-Attention（无残差） | 验证注意力机制 |

## 五、训练策略

### 5.1 显存自适应配置

自动检测 GPU 显存选择最佳配置：

| 空闲显存 | 图像尺寸 | 批次大小 | FP16 |
|----------|----------|----------|------|
| ≥10 GB | 512 | 16 | ✅ |
| 6-10 GB | 512 | 8 | ✅ |
| 4-6 GB | 384 | 8 | ✅ |
| <4 GB | 256 | 4 | ❌ |

### 5.2 干跑验证

训练前先执行一个 batch，提前触发 OOM，避免训练中途崩溃。

### 5.3 早停机制

patience = 20：连续 20 epoch 验证损失无改善则停止训练。

## 六、评估指标

### 6.1 检测任务

| 指标 | 说明 |
|------|------|
| R² | 决定系数，衡量密度预测精度 |
| RMSE | 均方根误差 |
| MAE | 平均绝对误差 |
| mIoU | 平均 IoU，定位精度 |
| 违反率 | 单调性违反百分比 |

### 6.2 分割任务

| 指标 | 说明 |
|------|------|
| Dice | Dice 系数，衡量掩膜重叠度 |
| IoU | 交并比 |

## 七、实验设计

### 7.1 消融实验

运行所有变体，对比各组件贡献：

```bash
python run_train.py --mode ablation --epochs 50
```

### 7.2 时间偏移预测

验证模型对未来的预测能力：

```bash
python run_train.py --mode train --predict_offset 0  # 当前
python run_train.py --mode train --predict_offset 1  # 0.05s 后
python run_train.py --mode train --predict_offset 2  # 0.1s 后
```

### 7.3 批量对比实验

使用批量训练工具对比不同配置：

```bash
python train_launcher.py --quick "resnet18,100,0,detection" "vit_small,100,0,detection"
```
