## 五、代码使用

### 5.1 导入

```python
from utils.console import (
    print_title,    # 章节标题
    print_result,    # 关键指标
    print_info,      # 普通信息
    print_warning,    # 警告
    print_error,     # 错误
    print_success,   # 成功
    print_results_table,  # 指标表格
)
```

### 5.2 使用示例

```python
# 打印标题
print_title("开始训练...")

# 打印指标（青色高亮）
print_result("R2", 0.9399)
print_result("违反率", 51.5, fmt=".1f", unit="%")

# 打印表格
print_results_table({
    "R2": 0.9399,
    "RMSE": 0.0522,
    "MAE": 0.0461,
})

# 打印警告
print_warning("显存不足，建议降低batch_size")

# 打印成功
print_success("模型保存成功")
```
