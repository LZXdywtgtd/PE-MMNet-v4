# 控制台输出样式指南

> PE-MMNet v4 训练输出样式说明

---

## 颜色对照表

| 颜色 | 样式函数 | 用途 |
|------|----------|------|
| 青色 | `print_result()` | 关键指标、评估结果 |
| 白色加粗 | `print_title()` | 章节标题 |
| 灰色 | `print_info()` | 普通日志 |
| 黄色 | `print_warning()` | 警告提示 |
| 红色 | `print_error()` | 错误信息 |
| 绿色 | `print_success()` | 成功提示 |

盒子说明：

- **Valid行**：R2、RMSE、MAE、违反率
- **System行**：EMA、ETA、预计完成时间、置信区间

## 代码使用

```python
from utils.console import (
    print_title,    # 章节标题
    print_result,   # 关键指标
    print_info,     # 普通信息
    print_warning,   # 警告
    print_error,    # 错误
    print_success,  # 成功
)

print_title("开始训练...")
print_result("R2", 0.9399)
print_warning("显存不足")
```
