## 三、模型变体详解

### 3.1 基础模型：PETSNetMultimodal（`resnet18`）

```
输入
├── 1D分支：(B, 300) 温度序列
│   ├── Micro1DCNN → 局部特征 (32维)
│   ├── Macro1DCNN → 全局趋势 (32维)
│   ├── Multi-Head Self-Attention → 通道融合
│   └── 输出：64维向量
│
└── 2D分支：(B, 2, H, W) 温度场+应力场
    ├── ResNet-18（ImageNet预训练）
    │   └── 输出：(B, 512, H', W')
    └── GlobalAvgPool → (B, 512) 向量

融合：CrossAttentionFusion
输出：MultiTaskHead → (B, 6) [x, y, l, w, conf, density]
```

**显存占用**：~2GB（batch=4，FP16）

---

### 3.2 SwinYOLOFPN（`swin_yolo`）

```
输入
├── 1D分支：同 PETSNetMultimodal → 64维
│
└── 2D分支：(B, 2, 512, 512)
    ├── SwinBackbone2D（timm Swin-Tiny，img_size=512）
    │   └── 输出多尺度特征：[(B,96,H/4,W/4), (B,192,H/8,W/8), (B,384,H/16,W/16), (B,768,H/32,W/32)]
    ├── 取最后一层 (B, 768, 16, 16)
    ├── yolo_proj：Conv2d(768→256) + BN + ReLU
    └── YOLOFPNHead：Conv2d(256→6) → (B, 6, 16, 16) → (B, 256, 6)

融合：CrossAttentionFusion(dim_2d=6, dim_1d=64)
输出：MultiTaskHead → (B, 6)

训练模式：返回 (B, 256, 6) 完整网格预测
推理模式：取最高conf网格 → CrossAttentionFusion → MultiTaskHead → (B, 6)
```

**显存占用**：~4GB（batch=4，FP16）

---

### 3.3 ViTYOLOFPN（`vit_yolo`）

```
输入
├── 1D分支：同 PETSNetMultimodal → 64维
│
└── 2D分支：(B, 2, 512, 512)
    ├── input_resize：Conv2d(2→3) + BN + ReLU（512→224）
    ├── ViTYOLOBackbone2D（timm vit_small_patch16_224，img_size=224）
    │   └── 输出：(B, 384, 14, 14)
    ├── interp：Resize到 (16, 16)
    ├── proj：Conv2d(384→256) + BN + ReLU
    └── YOLOFPNHead：Conv2d(256→6) → (B, 6, 16, 16) → (B, 256, 6)

融合：CrossAttentionFusion(dim_2d=6, dim_1d=64)
输出：MultiTaskHead → (B, 6)

训练模式：返回 (B, 256, 6) 完整网格预测
推理模式：取最高conf网格 → CrossAttentionFusion → MultiTaskHead → (B, 6)
```

**显存占用**：~3GB（batch=4，FP16）

---

### 3.4 SwinYOLOFPNWithPatchTST（`swin_yolo_patchtst`）

```
输入
├── 1D分支：(B, 300) 温度序列
│   ├── PatchEmbedding：patch_len=10 → d_model=64
│   ├── 可学习位置编码
│   ├── Transformer Encoder（2层，4头）
│   └── 输出：64维向量
│
└── 2D分支：(B, 2, 512, 512)
    ├── SwinBackbone2D（timm Swin-Tiny，img_size=512）
    │   └── 输出多尺度特征，取最后一层 (B, 768, 16, 16)
    ├── yolo_proj：Conv2d(768→256)
    └── YOLOFPNHead：→ (B, 256, 6)

融合：CrossAttentionFusion(dim_2d=6, dim_1d=64)
输出：MultiTaskHead → (B, 6)

训练模式：返回 (B, 256, 6) 完整网格预测
推理模式：取最高conf网格 → CrossAttentionFusion → MultiTaskHead → (B, 6)
```

**显存占用**：~4GB（batch=4，FP16）

**优势**：
- PatchTST 比 TemporalFeatureExtractor 更适合长序列时序建模
- Patch 机制捕获局部时序模式
- Transformer 全局注意力捕获长程依赖

---

### 3.5 DETRStyle（`detr`）

```
输入
├── 1D分支：同 PETSNetMultimodal → 64维
│
└── 2D分支：(B, 2, 512, 512)
    ├── ResNet18Backbone2D（启用 set_spatial_output=True）
    │   └── 输出：(B, 512, 32, 32)
    ├── input_proj：Conv2d(512→512)
    ├── PositionalEncoding2D：添加2D正弦位置编码
    ├── flatten + transpose：→ (B, 1024, 512)
    ├── TransformerEncoder（6层）
    │   └── 输出：(B, 1024, 512)
    ├── DETRDecoder（6层，100个Object Queries）
    │   └── 输出：(B, 100, 512)
    └── DETRHead：MLP → (B, 100, 6)

融合：CrossAttentionFusion(dim_2d=6, dim_1d=64)

训练模式：返回 (B, 100, 6) 完整query预测（不做融合）
推理模式：取最高conf query → CrossAttentionFusion → MultiTaskHead → (B, 6)
```

**显存占用**：~5GB（batch=4，FP16）

## 四、损失函数选择

| 变体 | 损失函数 | 目标分配 |
|------|----------|----------|
| `resnet18` | `MultimodalCrackLoss` | 直接比较（6维向量L1/L2） |
| `swin_yolo` | `YOLOLoss` | `YOLOTargetAssigner`（网格分配） |
| `vit_yolo` | `YOLOLoss` | `YOLOTargetAssigner`（网格分配） |
| `swin_yolo_patchtst` | `YOLOLoss` | `YOLOTargetAssigner`（网格分配） |
| `detr` | `DETRLoss` | `HungarianMatcher`（最优匹配） |

## 五、推理模式设计

所有新变体（swin_yolo/vit_yolo/detr）统一使用 `self.training` 属性区分模式：

```python
if self.training:
    return raw_pred, global_density  # 用于损失计算
else:
    # 取最佳预测 → 融合 → 输出头
    output = self.output_head(self.fusion(best_pred, feat_1d))
    return output, global_density
```

**关键原则**：
- 训练模式：返回原始预测（供损失函数使用）
- 推理模式：经过融合+输出头（用于实际预测）
