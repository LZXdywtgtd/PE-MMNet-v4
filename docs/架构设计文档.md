## 一、新增功能：队列配置向导 (B+C 流程)

### 1.1 设计理念

用户需求：
- **B**: 配置完一条命令 → 加入队列 → 配置下一条 → 加入队列 → 全部完成后批量执行
- **C**: 有一个专门的"配置向导"，一步一步引导，配置完自动添加到队列

### 1.2 新流程

```
python train_launcher.py
      │
      ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 主菜单                                                               │
│                                                                       │
│   【单次训练】                                                         │
│     [1] 快速训练（预设模板）                                            │
│     [2] 自定义配置（详细参数说明）                                      │
│     [3] 消融实验                                                      │
│                                                                       │
│   【批量训练】                                                         │
│     [4] 队列配置向导 ⭐ 逐步配置，自动加入队列                          │
│     [5] 添加到现有队列                                                │
│                                                                       │
│   当前队列: X 条命令                                                   │
│   [r] ▶ 开始批量训练  [v] 查看队列  [c] 清空队列                       │
└─────────────────────────────────────────────────────────────────────┘
      │
      ▼ 选择 [4] 队列配置向导
┌─────────────────────────────────────────────────────────────────────┐
│ 队列配置向导                                                          │
│                                                                       │
│   当前队列: 2 条命令                                                   │
│                                                                       │
│   [1] 使用预设模板                                                    │
│   [2] 自定义配置（详细参数说明）                                        │
│   [3] 快捷配置（基础参数）                                             │
│                                                                       │
│   [s] ▶ 开始训练                                                      │
│   [v] 查看队列  [q] 返回主菜单                                         │
└─────────────────────────────────────────────────────────────────────┘
      │
      ▼ 配置完成后
┌─────────────────────────────────────────────────────────────────────┐
│ ✅ 已添加到队列                                                        │
│    resnet18_cnn_attn_offset0 | detection | 100 epochs | offset=0    │
│                                                                       │
│ 按回车继续配置下一条命令...                                            │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.3 配置方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| [1] 预设模板 | 从预设中选择 | 快速添加标准配置 |
| [2] 自定义配置 | 详细参数 + `?` 查看说明 | 需要精确控制每个参数 |
| [3] 快捷配置 | 基础参数快速设置 | 快速批量添加 |

### 1.4 新增函数

```python
# launcher.py

    """
    队列配置向导 (B+C 流程)

    Args:
        launcher_callback: 回调对象，需要有 trainer 属性

    Returns:
        str: "start_training" 或 None
    """
```

### 4.2 批量训练执行流程

```
BatchTrainer.execute_all()
      │
      ▼
┌─────────────────────────────────────────────────────────────────────┐
│ for cmd in commands:                                                 │
│                                                                       │
│   1. 检查检查点是否存在                                              │
│      ├─ 存在 → cmd.status = SKIPPED（不训练）                        │
│      │   └─→ 应自动调用 _evaluate_checkpoint() 获取指标              │
│      └─ 不存在 → _execute_single(cmd)                               │
│                                                                       │
│   2. _execute_single(cmd)                                           │
│      ├─ subprocess.Popen(['python', 'run_train.py', ...])           │
│      ├─ 实时读取输出到日志文件                                       │
│      └─ 返回 checkpoint_path                                        │
│                                                                       │
│   3. _evaluate_checkpoint(ckpt_path)                                │
│      └─ subprocess.run(['python', 'run_train.py', '--mode', 'eval'])│
│      └─ 应检查 returncode                                           │
│                                                                       │
│   4. 解析评估指标 (R², RMSE, mIoU, etc.)                           │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.3 训练核心 (run_train.py)

```
main()
  │
  ├─ parse_args()
  ├─ set_seed(42)
  ├─ get_device()                    # cuda / cpu
  ├─ get_arch_specific_config()      # 架构自适应学习率
  ├─ auto_select_config()            # 显存自适应配置 ← 需要修复 TODO
  │
  ├─ mode == 'train':
  │    └─ train_variant(variant_key, config, device)
  │         ├─ 创建模型（当前未使用 ModelClass ← 需修复）
  │         ├─ create_multibatch_dataloaders()
  │         └─ train_model(model, train_loader, test_loader, config, device)
  │              ├─ 干跑验证（提前触发OOM）
  │              ├─ 训练循环 (FP16 + GradScaler)
  │              └─ 早停机制 (patience=20)
  │
  ├─ mode == 'eval':
  │    └─ eval_checkpoint(checkpoint, device)
  │         ├─ 从文件名推断任务和参数（不完整 ← 需修复）
  │         ├─ 创建模型
  │         ├─ 加载权重
  │         └─ evaluate_model()
  │
  └─ mode == 'ablation':
       └─ 遍历 VARIANT_MODELS
           └─ train_variant() + evaluate_model()
```

## 六、已发现的问题

### 🔴 严重问题

| # | 问题 | 位置 | 影响 | 关联 |
|---|------|------|------|------|
| 1 | `train_variant()` 计算了 `ModelClass` 但实际总是实例化 `PETSNetMultimodal` | run_train.py | **消融实验无效**，所有变体都是同一模型 | #2 |
| 2 | 检查点文件名不包含 `variant_key` | run_train.py | 不同变体互相覆盖，无法区分 | #1, #10 |
| 3 | 已有检查点时"继续训练"直接返回，不训练 | run_train.py | **无法真正继续训练** | #13 |

### 🟠 高优先级

| # | 问题 | 位置 | 影响 | 建议 |
|---|------|------|------|------|
| 4 | `--force_retrain` 参数在 batch_train_gui.py 生成，但 run_train.py 不接受 | tools/batch_train_gui.py / run_train.py | 强制重训练选项无效 | 添加到 run_train.py 或移除 |
| 5 | 多任务标签可能是 `(mask, detection)` 元组，统一调用 `labels.to(device)` 会报错 | run_train.py | **多任务模式训练会崩溃** | 解包后再 `.to(device)` |
| 6 | 多任务评估中 `target_mask` 可能未定义 | run_train.py | 某些分支会报 `UnboundLocalError` | 修复分支逻辑 |
| 7 | 批量评估不检查子进程返回码 | tools/batch_train_gui.py | **失败可能返回全零指标** | 检查 returncode |
| 8 | `eval_checkpoint()` 没有使用检查点保存的配置重建模型 | run_train.py | 评估可能与训练配置不一致 | 保存并恢复完整 config |
| 9 | 跳过已有检查点时不自动评估 | tools/batch_train_gui.py | 对比表缺失数据 | SKIPPED 时自动评估 |
| 10 | `ResultsComparator` 重新评估时丢失 `image_size` | tools/batch_train_gui.py | 对比结果可能不准确 | 传递 image_size 参数 |
| 11 | 两份 `train_launcher.py` 重复实现 | ~~根目录/tools/~~ | **维护风险**，容易漂移 | ~~已删除 tools/ 版本~~ |

### 10.1 检查点配置一致性

```python
        'fp16_enabled': True,
        # ... 其他关键参数

    'best_loss': best_loss,
}
```

```python
from tools.batch_train_gui import TrainingCommand, generate_id
```
