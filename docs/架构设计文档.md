## 三、调用链

### 3.1 训练模式

```
run_train.py --mode train
    ├─ auto_select_config()     # 显存自适应
    ├─ staged_training()        # 分阶段训练（可选）
    │    └─ train_model()      # 训练循环
    └─ evaluate_model()         # 评估
```

### 3.2 团队协作

```
team_train.py
    └─ run_training_task()     # 执行训练任务
         └─ subprocess.run(['python', 'run_train.py', ...])
```

## 四、模型架构

### 4.1 基础模型 (PETSNetMultimodal)

```
输入
├── 1D: (B, 300) → Micro+Macro CNN → Self-Attention → 64维
└── 2D: (B, 2, H, W) → ResNet-18 → 512维

融合: Cross-Attention → 输出Head
```

### 4.2 模型变体

| 变体 | 模型文件 | 说明 | 性能等级 |
|------|----------|------|----------|
| `resnet18` | pe_tsnet_multimodal.py | ResNet-18 + Cross-Attn | L1 |
| `swin_yolo` | pe_tsnet_yolo.py | Swin-Tiny + FPN + YOLO | L1+ |
| `vit_yolo` | pe_tsnet_yolo.py | ViT-Small + FPN + YOLO | L1 |
| `detr` | pe_tsnet_detr.py | ResNet-18 + Transformer | L1+ |

## 五、数据流

```
                                    ↓
                           create_multibatch_dataloaders()
                                    ↓
                           train_loader, test_loader
                                    ↓
                           train_model() → evaluate_model()
                                    ↓

```

## 六、损失函数选择

| 变体 | 损失函数 | 目标分配 |
|------|----------|----------|
| `resnet18` | MultimodalCrackLoss | 直接比较 |
| `swin_yolo` | YOLOLoss | YOLOTargetAssigner |
| `vit_yolo` | YOLOLoss | YOLOTargetAssigner |
| `detr` | DETRLoss | HungarianMatcher |

## 七、高级功能模块

| 模块 | 文件 | 说明 |
|------|------|------|
| SEBlock | pe_tsnet_multimodal.py | 通道注意力 |
| CoordAtt | pe_tsnet_multimodal.py | 坐标注意力 |
| GatedMultimodalFusion | pe_tsnet_fusion.py | 门控融合 |
| PatchTST1D | pe_tsnet_patchtst.py | 分块Transformer |

## 九、显存自适应

```python
≥10 GB → image_size=512, batch_size=16, fp16=True
6-10 GB → image_size=512, batch_size=8, fp16=True
4-6 GB  → image_size=384, batch_size=8, fp16=True
<4 GB   → image_size=256, batch_size=4, fp16=False
```
