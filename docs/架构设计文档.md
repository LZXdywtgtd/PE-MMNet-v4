## 三、调用链

### 3.1 训练模式

```
train_launcher.py
    └─→ run_train.py --mode train
         ├─ auto_select_config()     # 显存自适应
         ├─ train_variant()          # 训练变体
         │    └─→ train_model()      # 训练循环
         └─→ evaluate_model()        # 评估
```

### 3.2 批量训练

```
train_launcher.py
    └─→ InteractiveCLI._start_training()
         └─→ BatchTrainer.execute_all()
              ├─ _execute_single()   # 执行单条命令
              │    └─→ subprocess.run(['python', 'run_train.py', ...])
              └─→ _evaluate_checkpoint()  # 评估
```

## 六、显存自适应策略

```python
def auto_select_config(args):
    # 用户显式指定 → 使用用户值
    # 用户未指定 → 根据显存选择
    #
    # ≥10 GB → image_size=512, batch_size=16, fp16=True
    # 6-10 GB → image_size=512, batch_size=8, fp16=True
    # 4-6 GB  → image_size=384, batch_size=8, fp16=True
    # <4 GB   → image_size=256, batch_size=4, fp16=False
```

## 七、检查点命名

格式：`{variant}_{backbone_2d}_{backbone_1d}_{fusion}_task{task}_offset{offset}_best.pt`

示例：
- `full_resnet18_cnn_attn_cross_attn_taskdetection_offset0_best.pt`
- `1d_only_resnet18_cnn_attn_cross_attn_taskdetection_offset0_best.pt`

---

## 八、模型变体

| 变体 | 模型类 | 说明 |
|------|--------|------|
| `full` | PETSNetMultimodal | 完整双分支+Cross-Attention |
| `1d_only` | Model1DOnly | 仅 1D 时序分支 |
| `2d_only` | Model2DOnly | 仅 2D 图像分支 |
| `concat` | ModelConcat | 双分支拼接融合 |
| `add` | ModelAdd | 双分支加法融合 |
| `cross_attn` | ModelCrossAttn | Cross-Attention（不含残差） |

---

## 九、任务模式

| 任务 | 输出维度 | 损失函数 |
|------|----------|----------|
| `detection` | (batch, 6) | MultimodalCrackLoss |
| `segmentation` | (batch, 1, 256, 256) | SegmentationLoss |
| `multitask` | (mask, detection) | MultimodalSegmentationLoss |

## 十、评估指标

```python
def evaluate_model(...) -> dict:
    return {
        'r2': float,           # 决定系数
        'rmse': float,         # 均方根误差
        'mae': float,          # 平均绝对误差
        'mIoU': float,         # 平均 IoU
        'violation_rate': float,  # 单调性违反率
        'dice': float,         # Dice 系数（分割任务）
    }
```
