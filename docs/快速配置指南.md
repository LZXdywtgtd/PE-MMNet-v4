# 快速配置指南

> PE-MMNet v4 首次使用必读

---

## 一、环境检查

### 1.1 Python 版本

```bash
python --version
```

**要求**：Python 3.8 或更高版本

### 1.2 安装依赖

```bash
pip install -r requirements.txt
```

### 1.3 验证 PyTorch

```bash
python -c "import torch; print(f'PyTorch: {torch.__version__}'); print(f'CUDA: {torch.cuda.is_available()}')"
```

---

## 二、数据路径配置

### 2.1 自动配置（推荐）

首次运行会自动提示：

```bash
python train_launcher.py
```

### 2.2 手动配置

创建 `config.json`：

```json
{
  "data_root": "D:\\你的路径\\参考输入",
  "checkpoints_dir": "./checkpoints",
  "results_dir": "./benchmark_results"
}
```

### 2.3 数据目录结构

**文件夹名称无所谓，代码会自动扫描！**

```
data_root/
├── 实验A/
│   ├── 温度/d001.png, d002.png, ...
│   ├── 应力/d001.png, d002.png, ...
│   ├── 表格/Table_表面最大值.csv  # 可选
│   └── d_hist/d001.png, d002.png, ...  # 分割标签，可选
└── 实验B/
    ├── 温度/x001.png, x002.png, ...
    └── 应力/x001.png, x002.png, ...
```

| 文件夹 | 必须？ | 说明 |
|---------|--------|------|
| 温度/ | ✅ | PNG图像 |
| 应力/ | ✅ | PNG图像 |
| 表格/ | ❌ | CSV标签 |
| d_hist/ | ❌ | 分割掩膜 |

---

## 三、开始训练

### 3.1 团队协作（推荐新手）

```bash
python team_train.py
```
选择数字即可训练！

### 3.2 交互式菜单

```bash
python train_launcher.py
```

### 3.3 直接训练

```bash
# 检测模式
python run_train.py --mode train --epochs 100

# 分割模式
python run_train.py --mode train --task segmentation --epochs 100
```

---

## 四、常用参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--epochs` | 150 | 训练轮数 |
| `--batch_size` | 自动 | 批次大小 |
| `--lr` | 3e-4 | 学习率 |
| `--image_size` | 512 | 图像尺寸 |

### 模型变体

```bash
# YOLO系列
python run_train.py --variant swin_yolo --epochs 100 --lr 1e-4

# 优化组合
python run_train.py --variant resnet18 --fusion gated --use_coord_attn --epochs 100
```

### 任务模式

| 参数 | 输出 |
|------|------|
| `--task detection` | [x, y, l, w, conf, density] |
| `--task segmentation` | 二值掩膜 |

---

## 五、显存配置

系统自动检测显存并选择配置：

| 空闲显存 | 图像尺寸 | 批次大小 | FP16 |
|----------|----------|----------|------|
| ≥10 GB | 512 | 16 | ✅ |
| 6-10 GB | 512 | 8 | ✅ |
| 4-6 GB | 384 | 8 | ✅ |
| <4 GB | 256 | 4 | ❌ |

---

## 六、常见问题

| 问题 | 解决方案 |
|------|----------|
| `CUDA: False` | `pip install torch --index-url https://download.pytorch.org/whl/cu118` |
| "未找到数据批次" | 检查 `config.json` 中的 `data_root` |
| Loss 是 NaN | `--lr 1e-4` |
| 显存不足 | `--image_size 256 --batch_size 4` |
