# 快速配置指南

> **PE-MMNet v4 首次使用必读**
>
> 本文档指导您完成环境配置和数据路径设置。
>
> **重要提示**：推荐使用 `train_launcher.py` 作为统一入口，支持单次训练和批量训练。

---

## 一、训练入口选择

PE-MMNet v4 提供两种训练方式：

### 1.1 统一启动器（推荐）

使用 `train_launcher.py` 作为统一入口：

```bash
# 单次训练（交互式）
python train_launcher.py

# 批量训练（交互式）
python train_launcher.py --batch

# 快捷批量训练
python train_launcher.py --quick "resnet18,100,0,detection" "vit_small,100,0,detection"
```

**功能**：
- 预设模板快速启动
- 交互式自定义配置
- 消融实验预设
- 批量训练 + 结果对比

### 1.2 直接训练（高级用户）

直接调用 `run_train.py`：

```bash
# 训练完整模型
python run_train.py --mode train --variant full --epochs 150

# 评估检查点
python run_train.py --mode eval --checkpoint ./checkpoints/xxx.pt
```

## 二、安装依赖

### 2.1 基础依赖

```bash
cd project_v4
pip install -r requirements.txt
```

### 2.2 PyTorch 安装（关键）

**GPU用户**（推荐）：
```bash
# 访问 https://pytorch.org/ 查找适合您CUDA版本的命令
# 例如 CUDA 11.8:
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

**CPU用户**：
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

### 2.3 验证安装

```bash
python -c "import torch; print(f'PyTorch版本: {torch.__version__}'); print(f'CUDA可用: {torch.cuda.is_available()}')"
```

**预期输出**：
```
PyTorch版本: 2.x.x
CUDA可用: True   # 或 False（如果没装GPU版）
```

## 三、数据路径配置

### 3.1 首次运行自动配置

```bash
python train_launcher.py
```

首次运行时会提示：

```
============================================================
  首次运行配置
============================================================

请输入数据根目录路径（包含 单次扫描、参数化扫描1、参数化扫描2）

默认路径示例: [你的数据根目录]\参考输入

数据根目录: _
```

**输入您本地的数据路径**，按回车即可。

配置会自动保存到 `config.json`。

### 3.2 手动配置

如果需要手动修改配置，直接编辑 `config.json`：

```json
{
  "data_root": "D:\\你的路径\\参考输入",
  "output_dir": "./output",
  "checkpoints_dir": "./checkpoints",
  "results_dir": "./benchmark_results"
}
```

### 3.3 数据目录要求

数据根目录应包含以下子目录：

```
数据根目录/
├── 单次扫描/
│   ├── 温度/
│   ├── 应力/
│   ├── d/
│   └── 表格/
│       ├── Table_表面最大值.csv     # 必须
│       └── Table_Temp.csv          # 可选（v4.2.1+ 自动适配）
├── 参数化扫描1/
│   └── ...
└── 参数化扫描2/
    └── ...
```

> **注意**：探针CSV不再是必须的（v4.2.1+）。如果没有探针CSV，系统会自动使用标签CSV中的温度数据生成时序。如果完全没有CSV，系统会使用默认温度序列进行训练。

## 五、常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `torch.cuda.is_available()` 返回 False | 未安装GPU版PyTorch | 重新安装：`pip install torch --index-url https://download.pytorch.org/whl/cu118` |
| 提示"未找到数据批次" | config.json中路径错误 | 修改 `config.json` 中的 `data_root` |
| 训练loss是NaN | 学习率过高 | 使用 `--lr 1e-4` |
| 显存不足 | batch_size或image_size过大 | 自动降级，或使用 `--image_size 256 --batch_size 4` |
| 满屏乱码 | Windows控制台编码问题 | 这是正常的，颜色输出，不影响功能 |

### 5.1 恢复默认配置

如果配置出错，可以删除 `config.json` 重新配置：

```bash
del config.json
python train_launcher.py
```

## 六、快速命令参考

### 6.1 统一启动器（推荐）

```bash
# 单次训练 - 交互式选择预设
python train_launcher.py

# 单次训练 - 预设模板
python train_launcher.py    # 选择 [1] 快速训练 → [1] CNN 基线

# 批量训练 - 交互式
python train_launcher.py --batch

# 批量训练 - 快捷模式
python train_launcher.py --quick "resnet18,100,0,detection" "vit_small,100,0,detection"
```

### 6.2 直接训练（高级用户）

```bash
# 训练检测模型（默认）
python run_train.py --mode train --epochs 100

# 训练分割模型
python run_train.py --mode train --task segmentation --epochs 100

# 训练多任务模型
python run_train.py --mode train --task multitask --epochs 100

# 评估模型（检测模式）
python run_train.py --mode eval --checkpoint ./checkpoints/resnet18_cnn_attn_cross_attn_taskdetection_offset0_best.pt

# 调整参数
python run_train.py --mode train --batch_size 8 --lr 1e-4

# 时间偏移预测（预测未来裂纹）
python run_train.py --mode train --predict_offset 1  # 预测 0.05s 后
python run_train.py --mode train --predict_offset 2  # 预测 0.1s 后

# 高分辨率训练（支持 256/384/512/768/1024，默认512）
python run_train.py --mode train --image_size 512   # 512x512（默认）
python run_train.py --mode train --image_size 256   # 256x256 低分辨率（显存受限用）

# 显存自适应（自动检测显存选择配置）
python run_train.py --mode train                    # 自动选择（默认512+FP16）
python run_train.py --mode train --batch_size 16    # 指定batch_size，image_size自动
python run_train.py --mode train --no_fp16          # 禁用FP16

# 强制指定配置（禁用自动降级）
python run_train.py --mode train --image_size 512 --batch_size 16 --no_fp16
```
