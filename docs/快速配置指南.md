# 快速配置指南

> PE-MMNet v4 首次使用必读

---

## 一、环境检查

### 1.1 Python 版本

```bash
python --version
```

**要求**：Python 3.8 或更高版本

### 1.2 安装依赖

```bash
pip install -r requirements.txt
```

### 1.3 验证 PyTorch

```bash
python -c "import torch; print(f'PyTorch: {torch.__version__}'); print(f'CUDA: {torch.cuda.is_available()}')"
```

**预期输出**：
```
PyTorch: 2.x.x
CUDA: True  # 或 False（CPU 模式）
```

## 二、数据路径配置

### 2.1 自动配置（推荐）

首次运行会自动提示：

```bash
python train_launcher.py
```

### 2.2 手动配置

创建 `config.json`：

```json
{
  "data_root": "D:\\你的路径\\参考输入",
  "checkpoints_dir": "./checkpoints",
  "results_dir": "./benchmark_results"
}
```

### 2.3 数据目录结构

**文件夹名称无所谓，代码会自动扫描！**

每个数据子文件夹的结构：

```
数据子文件夹/           ← 代码会自动扫描所有子文件夹
├── 温度/             ← ✅ 必须有 PNG 图像
├── 应力/             ← ✅ 必须有 PNG 图像
├── 表格/             ← 可选，有则用于标签
│   └── Table_表面最大值.csv  ← 任选一个CSV
├── d_hist/           ← 可选，仅分割/多任务模式需要
└── 探针CSV/          ← 可选，有则用于时序
```

**数据依赖详解**：

| 文件夹 | 必须？ | 说明 |
|---------|--------|------|
| **温度/** | ✅ 必须 | PNG图像，数量决定样本数 |
| **应力/** | ✅ 必须 | PNG图像（与温度图像一一对应） |
| **d_hist/** | ✅ 建议有 | 用于分割/多任务模式；无则分割任务输出全零掩膜 |
| **表格/** | ❌ 可选 | 有CSV则用于标签，无则用默认值 |
| **探针CSV** | ❌ 可选 | 有则用于时序插值，无则用默认值 |

> ⚠️ **建议保留 d_hist/**：虽然检测模式不需要，但做分割/多任务训练时必须用到。

**完整示例**：
```
data_root/
├── 实验A/
│   ├── 温度/d001.png, d002.png, ...
│   ├── 应力/d001.png, d002.png, ...
│   ├── 表格/Table_表面最大值.csv
│   └── d_hist/d001.png, d002.png, ...  ← 分割标签
└── 实验B/
    ├── 温度/x001.png, x002.png, ...
    ├── 应力/x001.png, x002.png, ...
    └── 表格/Table_Crack.csv
```

**无CSV时的行为**：
- 系统会使用**默认标签**（x=0.01, y=0.01, density=0）
- 系统会使用**默认温度序列**（1400°C恒定）
- 仅基于图像进行训练

> 💡 **文件夹和文件名都可以随意命名**，只要有 `温度/` 和 `应力/` 文件夹即可。

## 三、训练入口

### 3.1 统一启动器（推荐）

```bash
python train_launcher.py
```

菜单：
| 选项 | 功能 |
|------|------|
| `[1]` | 快速训练（预设模板） |
| `[2]` | 自定义配置（详细参数说明） |
| `[3]` | 消融实验 |
| `[4]` | 队列配置向导（批量训练） |
| `[5]` | 添加到现有队列 |
| `[r]` | 开始批量训练 |
| `[l]` | 加载配置 |
| `[s]` | 保存配置 |

### 3.2 快捷批量训练

```bash
python train_launcher.py --quick "resnet18,100,0,detection" "vit_small,100,0,detection"
```

格式：`backbone_2d,epochs,offset,task`

### 3.3 直接训练

```bash
# 检测模式
python run_train.py --mode train --epochs 100

# 分割模式
python run_train.py --mode train --task segmentation --epochs 100

# 评估
python run_train.py --mode eval --checkpoint ./checkpoints/xxx.pt
```

## 四、常用参数

### 4.1 训练参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--epochs` | 150 | 训练轮数 |
| `--batch_size` | 自动 | 批次大小（根据显存自动选择） |
| `--lr` | 3e-4 | 学习率 |
| `--dropout` | 0.2 | Dropout |
| `--image_size` | 512 | 图像尺寸：256/384/512/768/1024 |

### 4.2 模型架构

| 参数 | 默认值 | 选项 |
|------|--------|------|
| `--backbone_2d` | resnet18 | resnet18, vit_small |
| `--backbone_1d` | cnn_attn | cnn_attn, transformer, dlinear |
| `--fusion` | cross_attn | cross_attn, concat, adaptive |

### 4.3 任务模式

| 参数 | 输出 |
|------|------|
| `--task detection` | 6维向量 [x, y, l, w, conf, density] |
| `--task segmentation` | 256x256 二值掩膜 |
| `--task multitask` | 检测 + 分割 |

### 4.4 时间偏移

```bash
python run_train.py --predict_offset 0  # 当前时刻
python run_train.py --predict_offset 1  # 0.05秒后
python run_train.py --predict_offset 2  # 0.1秒后
```

## 五、显存配置

系统自动检测显存并选择配置：

| 空闲显存 | 图像尺寸 | 批次大小 | FP16 |
|----------|----------|----------|------|
| ≥10 GB | 512 | 16 | ✅ |
| 6-10 GB | 512 | 8 | ✅ |
| 4-6 GB | 384 | 8 | ✅ |
| <4 GB | 256 | 4 | ❌ |

**强制指定配置**：

```bash
# 指定 batch_size，image_size 自动
python run_train.py --batch_size 16

# 禁用 FP16
python run_train.py --no_fp16

# 完全手动指定
python run_train.py --image_size 512 --batch_size 16 --no_fp16
```

## 六、常见问题

| 问题 | 解决方案 |
|------|----------|
| `CUDA: False` | 安装 GPU 版 PyTorch：`pip install torch --index-url https://download.pytorch.org/whl/cu118` |
| "未找到数据批次" | 检查 `config.json` 中的 `data_root` 路径 |
| 训练 loss 是 NaN | 降低学习率：`--lr 1e-4` |
| 显存不足 | 使用 `--image_size 256 --batch_size 4` |
