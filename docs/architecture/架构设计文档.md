## 三、模型变体详解

### 3.1 基础模型：PETSNetMultimodal（`resnet18`）

```
输入
├── 1D分支：(B, 300) 温度序列
│   ├── Micro1DCNN → 局部特征 (32维)
│   ├── Macro1DCNN → 全局趋势 (32维)
│   ├── Multi-Head Self-Attention → 通道融合
│   └── 输出：64维向量
│
└── 2D分支：(B, 2, H, W) 温度场+应力场
    ├── ResNet-18（ImageNet预训练）
    │   └── 输出：(B, 512, H', W')
    └── GlobalAvgPool → (B, 512) 向量

融合：CrossAttentionFusion(dim_2d=512, dim_1d=64)
输出：MultiTaskHead(576→6) → (B, 6) [x, y, l, w, conf, density]
```

**显存占用**：~2GB（batch=4，FP16）

---

### 3.2 SwinYOLOFPN（`swin_yolo`）

```
输入
├── 1D分支：TemporalFeatureExtractor → 64维
│
└── 2D分支：(B, 2, 512, 512)
    ├── SwinBackbone2D（timm Swin-Tiny，img_size=512）
    │   └── 输出多尺度特征，取最后一层 (B, 768, G, G)，G=image_size/32
    ├── yolo_proj：Conv2d(768→256) + BN + ReLU
    └── YOLOFPNHead → (B, G², 6)

融合：CrossAttentionFusion(dim_2d=6, dim_1d=64)
输出：MultiTaskHead(70→6) → (B, 6)

训练模式：返回 (B, G², 6) 完整网格预测
推理模式：取最高conf网格 → fusion → output_head → (B, 6)
```

**grid_size 动态**：image_size=256 → G=8 → 64 grids；image_size=512 → G=16 → 256 grids

**显存占用**：~4GB（batch=4，FP16）

---

### 3.3 ViTYOLOFPN（`vit_yolo`）

```
输入
├── 1D分支：TemporalFeatureExtractor → 64维
│
└── 2D分支：(B, 2, 任意尺寸) 图像
    ├── input_resize：Conv2d(2→3, kernel_size=1) + BN + ReLU（转换为3通道）
    ├── ViTYOLOBackbone2D（timm vit_small_patch16_224）
    │   └── 输出：(B, 256, 7, 7)（注意：骨干输出已为256通道，无384→256投影）
    ├── interp：Resize到 (16, 16)
    ├── fpn：Conv2d(256→256, kernel_size=3) + BN + ReLU
    └── YOLOFPNHead → (B, 256, 6)

融合：CrossAttentionFusion(dim_2d=6, dim_1d=64)
输出：MultiTaskHead(70→6) → (B, 6)

训练模式：返回 (B, 256, 6) 固定网格
推理模式：取最高conf → fusion → output_head → (B, 6)
```

**⚠️ 注意**：grid_size 固定为 16×16=256，与 image_size 无关。图像会被 resize 回 224 处理。

**显存占用**：~3GB（batch=4，FP16）

---

### 3.4 SwinYOLOFPNWithPatchTST（`swin_yolo_patchtst`）

```
输入
├── 1D分支：(B, 300) PatchTST1D
│   ├── PatchEmbedding：patch_len=10 → 30 patches, d_model=64
│   ├── 可学习位置编码
│   ├── Transformer Encoder（2层，4头）
│   └── 输出：64维向量（与 TemporalFeatureExtractor 维度一致）
│
└── 2D分支：(B, 2, 512, 512)
    ├── SwinBackbone2D（timm Swin-Tiny）
    │   └── 输出多尺度特征，取最后一层 (B, 768, G, G)
    ├── yolo_proj：Conv2d(768→256)
    └── YOLOFPNHead → (B, G², 6)

融合：CrossAttentionFusion(dim_2d=6, dim_1d=64)
输出：MultiTaskHead(70→6) → (B, 6)

训练模式：返回 (B, G², 6) 完整网格预测
推理模式：取最高conf → fusion → output_head → (B, 6)
```

**优势**：
- PatchTST 比 TemporalFeatureExtractor 更适合长序列时序建模
- Patch 机制捕获局部时序模式
- Transformer 全局注意力捕获长程依赖
- 有 fallback 机制（导入失败时使用 TemporalFeatureExtractor）

**显存占用**：~4GB（batch=4，FP16）

---

### 3.5 DETRStyle（`detr`）

```
输入
├── 1D分支：TemporalFeatureExtractor → 64维
│
└── 2D分支：(B, 2, 256, 256)
    ├── ResNet18Backbone2D（启用 set_spatial_output=True）
    │   └── 输出：(B, 512, 8, 8)（固定，与 image_size 无关）
    ├── input_proj：Conv2d(512→512)
    ├── PositionalEncoding2D：动态匹配特征图尺寸
    ├── flatten + transpose → (B, 64, 512)
    ├── TransformerEncoder（6层）
    ├── DETRDecoder（100个Object Queries）
    └── DETRHead → (B, 100, 6)

训练链路：
  detr_pred (B, 100, 6)
  → Hungarian 匹配选最佳 query → best_query (B, 6)
  → query_proj(6→128)
  → fusion(dim_2d=128, dim_1d=64) → (B, 192)
  → output_head(192→6) → final_output (B, 6)
  loss = HungarianLoss(detr_pred) + 0.5×SuperviseLoss(final_output)

推理模式：
  detr_pred → argmax(conf) → best_query → query_proj → fusion → output_head → (B, 6)
```

**显存占用**：~5GB（batch=4，FP16）

## 四、损失函数选择

| 变体 | 损失函数 | 目标分配 |
|------|----------|----------|
| `resnet18` | `MultimodalCrackLoss` | 直接比较（6维向量L1/L2） |
| `swin_yolo` | `YOLOLoss` | `YOLOTargetAssigner`（网格分配，动态 grid_size） |
| `vit_yolo` | `YOLOLoss` | `YOLOTargetAssigner`（网格分配，固定 grid_size=16） |
| `swin_yolo_patchtst` | `YOLOLoss` | `YOLOTargetAssigner`（网格分配，动态 grid_size） |
| `detr` | `DETRLoss` | `HungarianMatcher`（最优匹配） |

## 五、训练/推理模式设计

所有新变体（swin_yolo/vit_yolo/detr/swin_yolo_patchtst）统一使用 `self.training` 属性区分模式：

```python
if self.training:
    return raw_pred, global_density  # 用于损失计算
else:
    # 取最佳预测 → 融合 → 输出头
    output = self.output_head(self.fusion(best_pred, feat_1d))
    return output, global_density
```

**关键原则**：
- 训练模式：返回原始预测（供损失函数使用）
- 推理模式：经过融合+输出头（用于实际预测）

## 八、检查点命名

格式：`{variant}_{backbone}_{fusion}_task{task}_offset{offset}_best.pt`

示例：`swin_yolo_resnet18_cnn_attn_cross_attn_taskdetection_offset0_best.pt`

**双保险机制**：
- `{...}_best.pt`：仅在验证损失改善时更新
- `{...}_last.pt`：每个 epoch 结束无条件保存（崩溃兜底）

**元数据字段**：
- `is_complete`：`True`=训练正常结束，`False`=意外中断
- `task_id`：任务ID（团队协作）
